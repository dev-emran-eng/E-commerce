# 🛒 E-commerce Backend API

A scalable and feature-rich E-commerce Backend API built with **Python, Django, Django REST Framework, and PostgreSQL**.

This project is being developed as a portfolio project to demonstrate backend development skills, REST API design, authentication, database relationships, business logic, validation, and testing.

## 🚀 Tech Stack

* Python
* Django
* Django REST Framework
* PostgreSQL
* JWT Authentication
* Git & GitHub

## 📌 Project Status

🚧 **Currently in development**

More features and documentation will be added as the project progresses.

## 🎯 Main Goals

* Build a production-style REST API
* Practice Django and Django REST Framework
* Design relational database models
* Implement authentication and authorization
* Build real-world e-commerce business logic
* Write API tests
* Document APIs properly

## 📂 Planned Features

* User Profile & Address
* Product Management

* Orders & Checkout
* Coupons & Discounts
* Product Reviews & Ratings
* Payment Management
